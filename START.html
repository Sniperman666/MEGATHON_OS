# What is MEGATHON?

MEGATHON is a sophisticated boot loader used to inject and patch data in memory, instead of on disk. This means that we're able to achieve a near-native experience on many unsupported Macs.

  • We recommend viewing the MEGATHON OS Terminology Page if you have questions.
  • For troubleshooting, join the MEGATHON OS Paradise Discord Server (opens new window) and see our Troubleshooting Page.

# How do I get started?

  1. The first step of ensuring whether your model is supported is by checking the Supported Models page.

  2. Download and build macOS Installer

  3. Run the MEGATHON-Patcher.app

  4. Reboot and boot MEGATHON
